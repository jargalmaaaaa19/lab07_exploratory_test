Тестлэсэн апп: багшийн өгсөн «Уншлагын жагсаалт» (app.js). 

## Агуулга

- `charter.md`: session-ээс өмнө бичсэн charter
- `session-report.md`: 60 минутын session-ий тайлан, түүхийн тэмдэглэлтэй
- `bugs/`: алдааны тайлангууд (BUG-01 ... BUG-06)
- `evidence/`: API согогийн `curl -i` гаралт
- `screenshots/`: UI согогийн скриншот

## Олдсон согогуудын товч

| ID | Согог | Ноцтой байдал | Аялал |
|---|---|---|---|
| BUG-01 | Давхардсан ном нэмэгдэж байна | Major | Fed-Ex |
| BUG-02 | Хайлт том/жижиг үсэг ялгаж байна | Major | Fed-Ex |
| BUG-03 | Он талбар хүрээ, бутархай, сөрөг утгыг хүлээн авч байна | Major | Saboteur |

| BUG-06 | «Нийт ном» тоолуур хүснэгтийн номын тооноос зөрж байна | Major | Fed-Ex |

## Дүгнэлт (debrief)

Хамгийн үр дүнтэй нь Couch Potato аялал байв: формын талбаруудыг хоосон орхиход Зохиолч, Он хоосон байхад ном нэмэгдэж байгааг (BUG-04) тэр дороо илрүүлсэн. Fed-Ex аялалаар оруулсан номыг хайлт болон хүснэгтээр дагахад давхардсан ном нэмэгдэж (BUG-01), хайлт том/жижиг үсэг ялгаж байгааг (BUG-02) олсон. Saboteur аялалаар он талбарт хүрээнээс гадуур, бутархай, сөрөг утга оруулахад баталгаажуулалт байхгүй (BUG-03) болох, мөн буруу JSON-д API 400 биш 200 OK буцаадаг (BUG-05) нь илэрсэн. Charter-аас гадуур санамсаргүй байдлаар «Нийт ном» тоолуур хүснэгтэд буй номын тооноос зөрж (11 ном байхад 12 гэж харуулсан) байгааг (BUG-06) олсон ба Устгах товч улаан биш байгааг тэмдэглэсэн боловч bug report болгоогүй. Шалгагдаагүй үлдсэн зүйл: бүх хуудас, линкийн ажиллагаа, маш урт оролт хүснэгтийг эвдэх эсэх, тусгай тэмдэгт хүснэгтэд зөв харагдах эсэх (зөвхөн хадгалагдаж байгааг шалгасан), мессежүүдийн үсгийн алдаа. Дараагийн session-ий charter нь тоолуурын зөрүү болон хүснэгтийн урт оролтыг гол чиглэл болгоно. Playwright автомат тест BUG-01, 03, 04 болон тоолуурын зөрүүг (өгөгдөл ба DOM-ийн утга шалгах тест бичсэн бол), мөн BUG-05-ыг (статус код шалгаж) барих байсан. BUG-02-ыг ч тохирох тест бичсэн бол барина, гэхдээ тэр тестийг хүн «том/жижиг үсгээр хайвал яах вэ» гэж бодож байж бичих ёстой. Устгах товчны өнгө, мессежийн утга ба үсгийн алдааг автомат тест ихэвчлэн барьдаггүй тул хүний нүд хэрэгтэй. Exploratory тест нь урьдчилан бичээгүй асуултыг гаргаж ирдгээрээ автомат тестээс ялгаатай, харин автомат тест олдсон согогийг дахин гарахаас хамгаалдаг.
