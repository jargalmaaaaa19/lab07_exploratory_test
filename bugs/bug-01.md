# BUG-01: POST /api/books руу буруу JSON биетэй хүсэлт илгээхэд сервер 400 биш 200 OK буцааж байна

Орчин:  Уншлагын жагсаалт v2.0, {{http://localhost:3000}}, Ubuntu (WSL2), 2026-10-16

Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам

1. Нэг терминалд `node app.js` ажиллуулна.
2. Өөр терминалд дараах командыг ажиллуулна (эвдэрсэн, дуусаагүй JSON илгээнэ):

       mkdir -p evidence
       curl -i -X POST localhost:3000/api/books -H 'Content-Type: application/json' -d '{"title":' 2>&1 | tee evidence/bug-05-curl.txt

3. Гаралтын эхний мөр буюу HTTP статусыг харна.

Хүлээгдэж байсан: Спецификац «API: буруу JSON биетэй POST хүсэлтэд 400 алдаа буцаана» гэж заасан. Статус нь `HTTP/1.1 400 ...` байх ёстой.

Бодит үр дүн:     Сервер `HTTP/1.1 200 OK` статус буцаана (бүтэн гаралт evidence/bug-05-curl.txt файлд).

Ноцтой байдал: Major. Буруу хүсэлтийг амжилттай гэж хариулснаар API-г ашиглаж буй клиент алдааг мэдэхгүй, буруу өгөгдөл хадгалагдах эрсдэлтэй.
