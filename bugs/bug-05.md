# BUG-05: «Нийт ном» тоолуур хүснэгтэд харагдаж буй номын тооноос 1-ээр илүү гарч байна

Орчин:  Уншлагын жагсаалт v2.0, Google Chrome 155.0.8059.80, Ubuntu WSL2 (Windows), 2026-10-16

Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан (анхны 3 ном)

## Дахин гаргах алхам

1. Браузераар `http://localhost:3000` хаягаар орно.
2. Хүснэгтийн мөрийг тоолно: 3 ном (`Тунгалаг Тамир`, `Clean Code`, `The Pragmatic Programmer`).
3. Хүснэгтийн доорх «Нийт ном» тоолуурыг харна.
4. Ном нэмж (Гарчиг: `Тест`, Зохиолч: `Тест`, Он: `2000`) «Нэмэх» товчийг дараад хүснэгтийн мөр, тоолуурыг дахин харьцуулна.

Хүлээгдэж байсан: Спецификац «'Нийт ном' тоолуур хүснэгтэд буй номын тоотой тэнцүү» гэж заасан. 3 дахь алхамд тоолуур 3, 4 дэх алхамд 4 байх ёстой.

Бодит үр дүн:     Тоолуур хүснэгтийн мөрийн тооноос үргэлж 1-ээр илүү байна: 3 ном байхад «Нийт ном: 4». Олон ном нэмсний дараа ч ижил: хүснэгтэд 11 ном байхад «Нийт ном: 12» (screenshots/bug-05.png).

Ноцтой байдал: Major. Хэрэглэгчид буруу тоон мэдээлэл харуулж байна. Өгөгдлийн хоёр харагдац (хүснэгт ба тоолуур) зөрж байгаа нь дотоод тооцооллын алдааг илтгэнэ.
