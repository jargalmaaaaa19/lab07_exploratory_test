# BUG-05: «Нийт ном» тоолуур хүснэгтэд харагдаж буй номын тооноос зөрж байна (хүснэгтэд 11 ном, тоолуур 12)

Орчин:  Уншлагын жагсаалт v2.0, Google Chrome Google Chrome 155.0.8059.80, Ubuntu WSL2 (Windows), 2026-10-16

Урьдчилсан нөхцөл: node app.js-ийг шинээр асаасан (анхны 3 ном, «Нийт ном: 3»)

## Дахин гаргах алхам

1. Браузераар `http://localhost:3000` хаягаар орно. Хүснэгтэд 3 ном, тоолуур 3 (зөв).
2. {{COUNTER_STEPS}}
3. Хүснэгтийн мөрийг тоолно.
4. Хүснэгтийн доорх «Нийт ном» тоолуурыг харна.

Хүлээгдэж байсан: Спецификац «'Нийт ном' тоолуур хүснэгтэд буй номын тоотой тэнцүү» гэж заасан. Хүснэгтэд 11 ном байвал тоолуур 11 байх ёстой.

Бодит үр дүн:     Хүснэгтэд 11 ном харагдаж байхад тоолуур «Нийт ном: 12» гэж харуулна.

Ноцтой байдал: Major. Хэрэглэгчид буруу тоон мэдээлэл харуулж байна. Өгөгдлийн хоёр харагдац (хүснэгт ба тоолуур) зөрж байгаа нь дотоод тооцооллын алдааг илтгэнэ.
